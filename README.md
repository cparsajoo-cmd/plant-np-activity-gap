# Measuring the enzyme-activity gap for plant natural products

How much of the chemical space of plant natural products has a recorded
activity against well-studied enzyme targets, and how much has none?

These scripts answer that question from two public datasets, so that the
figures can be regenerated by anyone rather than taken on trust.

## Data

| Source | Version used | Identifier |
|---|---|---|
| LOTUS, structure–organism pairs with literature references | frozen dataset, 13 April 2026 | doi:10.5281/zenodo.19360665 |
| ChEMBL, chemical representations | ChEMBL 37 | `chembl_37_chemreps.txt.gz`, EBI FTP |
| ChEMBL, bioactivities | live REST API | retrieved 3 November 2026 |

Both datasets are openly licensed. No unpublished or proprietary data is
used.

## Running

Python 3.8 or later. No third-party packages are required — the scripts use
only the standard library.

```
python3 fetch_data.py            # ~380 MB, resumes if interrupted
python3 01_fetch_panel.py        # queries ChEMBL, a few minutes
python3 02_map_lotus_chembl.py   # the mapping and the counts
python3 03_validate.py           # sanity check on a random sample
```

`02_map_lotus_chembl.py` writes `results.json` and prints every figure in the
tables below.

## Method

1. **Plant set.** From LOTUS, keep the structure–organism pairs whose organism
   phylum is *Streptophyta* (land plants). Their distinct InChIKeys form the
   plant natural-product set. Streptophyta rather than Archaeplastida, so that
   red and green algae are excluded.
2. **Presence in ChEMBL.** Match those structures to ChEMBL on the
   **connectivity layer** of the InChIKey — its first 14 characters, that is
   the molecular skeleton without stereochemistry. This is deliberately
   permissive: a permissive match finds *more* plant compounds in ChEMBL, so
   the gap it reports is a lower bound. The stricter full-key count is printed
   alongside for comparison.
3. **Measured activity.** For each panel target, retrieve every ChEMBL activity
   carrying a pChEMBL value, and intersect the resulting compound sets with the
   structures located in step 2.

## What these numbers do and do not show

- **Absence of a record is not evidence that no assay was performed.** The
  counts measure what is *recorded in ChEMBL*, which is a lower bound on what
  has been measured somewhere.
- **LOTUS is itself incomplete.** The per-target plant-derived shares are
  therefore lower bounds as well.
- *Streptophyta* is an operational definition of "plant" and is stated as such.
- Connectivity-level matching ignores stereochemistry. Two stereoisomers are
  treated as the same skeleton, which is the permissive direction.
